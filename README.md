# CSCE-676: Data Mining & Analysis – Semester Project

Welcome to my semester-long project for **CSCE-676: Data Mining & Analysis**. This repository documents my journey through the major stages of a comprehensive data mining project, from data selection to final analysis and presentation.

## 📊 Project Overview
This project aims to apply data mining and analysis techniques to a real-world dataset. Each milestone is captured in a Jupyter notebook, including code, visualizations, interpretations, and references. The project demonstrates the end-to-end process of extracting insights from data.

## 🚀 Features
- Step-by-step data mining workflow
- Exploratory data analysis and visualization
- Research question formulation and hypothesis testing
- In-depth analysis and interpretation
- Well-documented code and sources

## 🛠️ Usage
1. Clone the repository:
	```bash
	git clone https://github.com/Tyler-Keener/Data-Mining.git
	```

3. Follow along with each deliverable as the project develops.

## 📚 Requirements
- Python 3.10+
- Jupyter Notebook or JupyterLab
